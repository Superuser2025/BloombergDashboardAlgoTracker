═══════════════════════════════════════════════════════════════════════════════
HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

**ON STARTUP:**
1. Dashboard detects your screen size
2. Determines best layout mode (Full or Tabbed)
3. Configures fonts and spacing
4. Renders accordingly!

**SCREEN SIZE CLASSIFICATION:**

🔹 **SMALL SCREENS (< 1366px width)**
   - Typical laptops: 1280x720, 1366x768
   - Uses TABBED layout
   - Compact fonts and spacing
   - Single-column metrics where needed
   - Abbreviated labels (P&L instead of Profit & Loss)

🔹 **MEDIUM SCREENS (1366px - 1920px)**
   - Standard desktops: 1920x1080 (Full HD)
   - Uses FULL STACKED layout
   - Standard fonts and spacing
   - All modules visible at once
   - Full text labels

🔹 **LARGE SCREENS (> 1920px)**
   - 4K monitors: 2560x1440, 3840x2160
   - Uses FULL STACKED layout
   - Larger fonts for readability
   - Generous spacing
   - All features visible

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

**PROBLEM: Tabs not showing on laptop**
SOLUTION: Screen might be detected as medium. Resize MT5 window smaller.

**PROBLEM: Fonts too small to read**
SOLUTION: Screen classified as small. You can manually adjust in inputs.

**PROBLEM: Layout looks wrong**
SOLUTION: Check Experts tab for errors. Ensure all files compiled correctly.

**PROBLEM: Can't switch tabs**
SOLUTION: Make sure tabs are actually showing. Check if using small screen.
