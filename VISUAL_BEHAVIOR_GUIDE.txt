SCREEN SIZE BREAKPOINTS
═══════════════════════════════════════════════════════════════════════════════

< 1366px width:
   → SMALL SCREEN MODE
   → Tabbed layout
   → Compact everything
   → Perfect for: Laptops, small monitors, portable displays

1366px - 1920px width:
   → MEDIUM SCREEN MODE
   → Full stacked layout
   → Standard sizes
   → Perfect for: Full HD monitors, standard desktops

> 1920px width:
   → LARGE SCREEN MODE
   → Full stacked layout
   → Large sizes
   → Perfect for: 4K monitors, ultra-wide displays, trading setups

ADAPTIVE BEHAVIOR EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

EXAMPLE 1: Starting on laptop, moving to desktop
1. You start MT5 on laptop (1366px)
2. Dashboard detects SMALL screen → Shows tabs
3. You drag MT5 window to external monitor (1920px)
4. Dashboard detects MEDIUM screen → Removes tabs, shows all panels
5. Automatic adaptation!

EXAMPLE 2: Resizing MT5 window
1. You have dashboard on large monitor (2560px)
2. You resize MT5 window smaller (1200px)
3. Dashboard detects size change → Switches to tabbed mode
4. Immediate adaptation!

EXAMPLE 3: Multi-monitor setup
1. Small laptop screen (1366px) → Tabbed mode
2. Large external monitor (2560px) → Full stacked mode
3. Dashboard adapts to whichever screen it's on!
